## 아직 구현·검증하지 않은 항목

- USB/Bluetooth/Wi-Fi 외장 카메라 입력 드라이버 및 펌웨어.
- 홍채 무늬 등록/정합, IR 영상용 홍채 타원 분할 모델.
- 카메라 내부 파라미터·화면 외부 파라미터 보정과 기하학적 3D 시선 복원.
- 머리 위치의 정확한 cm 단위 측정, 사용자별 시각축 오프셋 보정.
- 실사용자 데이터로 학습·검증된 범용 무보정 시선 모델.
- 시선 키보드·LLM 문장 자동완성.
- GPT 화면 스크린샷 분석, 접근성 트리에 없는 UI 인식.
- 사용자 계정, 개인별 요금제, 실제 폰에서 GPT 보정 정확도 검증.

## 비교 실험

같은 참가자/거리/앱에서 로컬만, GPT 1만, 로컬+GPT 2, GPT 1+2를 비교합니다. 명시적 목표를 정답으로 사용하고 실제 클릭 위치를 정답으로 간주하지 않습니다. 타깃 선택 성공률, 오클릭 수, 선택 시간, 응답 지연, 보류율, 폐기된 오래된 응답 비율, API 토큰 비용을 기록합니다. 머리를 고정한 경우와 움직이는 경우를 분리합니다. API 키·얼굴 사진·화면 내용은 기본 로그에 기록하지 않습니다.
